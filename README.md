# Mathematical-Art

I found an artist named Hamid Naderi Yeganeh, that makes drawings using math equations. Some can be found [here](https://www.scientificamerican.com/blog/guest-blog/making-mathematical-art/) and his more complex art [here](https://x.com/naderi_yeganeh)

I'm interested in learning the process of making these drawings, with my current setup using primarily Python libraries (matplotlib, 
numpy, and sympy).
